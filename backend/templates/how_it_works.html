ಐದು ಬೇರೆ ಬೇರೆ ಕೆಲಸಗಳು ಇಲ್ಲಿ ನಡೆಯುತ್ತವೆ. ಯಾರು ಏನು ಮಾಡುತ್ತಾರೆ, ಸೈಟ್ ಏನು ಮಾಡುತ್ತದೆ ಮತ್ತು ಕಾಗದದಲ್ಲಿ ಏನು ಉಳಿಯುತ್ತದೆ ಎಂದು ನೋಡಿ.

One season, start to finish.

Five separate things happen here and they do not depend on each other. Follow one funded season from the first post to the final split, and see who does what, what the site does, and what stays on paper between people.

{% endif %}
1

{{ 'ಒಂದು ಯೋಜನೆ ಪ್ರಕಟವಾಗುತ್ತದೆ' if lang == 'kn' else 'A plan is posted' }}

{{ 'ಬೆಳೆಗಾರ' if lang == 'kn' else 'The grower' }}

Posts the parcel, district and survey number, the crop or animals, a costed budget, the expected yield, the split they want, and photographs.

{{ 'ಸೈಟ್' if lang == 'kn' else 'The site' }}

Shows the plan in full, in English and Kannada, with its budget arithmetic and a meter for how much is spoken for.

{{ 'ಕಾಗದದಲ್ಲಿ' if lang == 'kn' else 'On paper' }}

Nothing yet.

2

{{ 'ನೀವು ಓದಿ ಆಸಕ್ತಿ ದಾಖಲಿಸುತ್ತೀರಿ' if lang == 'kn' else 'You read it and register interest' }}

{{ 'ಹೂಡಿಕೆದಾರ' if lang == 'kn' else 'The investor' }}

Reads the plan properly, then registers interest with an amount. Nothing is paid and nothing is binding.

{{ 'ಸೈಟ್' if lang == 'kn' else 'The site' }}

Tells the grower whether the plan is fundable, and passes on your name, district and phone number. Pools are capped and kept small.

{{ 'ಕಾಗದದಲ್ಲಿ' if lang == 'kn' else 'On paper' }}

Nothing yet. Counsel reviews the structure before anything is signed.

3

{{ 'ಒಪ್ಪಂದ ಸಹಿ ಮಾಡಲಾಗುತ್ತದೆ' if lang == 'kn' else 'The agreement is signed' }}

{{ 'ಎರಡೂ ಕಡೆ' if lang == 'kn' else 'Both sides' }}

Sign on paper with your own witnesses, and agree the split, the costs and what happens if the season fails.

{{ 'ಸೈಟ್' if lang == 'kn' else 'The site' }}

Does not hold money or execute anything. It is not a party to the agreement.

{{ 'ಕಾಗದದಲ್ಲಿ' if lang == 'kn' else 'On paper' }}

A deed or partnership agreement for that crop on that parcel, for a fixed term.

4

{{ 'ಋತು ನಡೆಯುತ್ತದೆ' if lang == 'kn' else 'The season runs' }}

{{ 'ಬೆಳೆಗಾರ' if lang == 'kn' else 'The grower' }}

Works the land and posts updates: what was spent, what went in the ground, anything that changed against the plan.

{{ 'ಹೂಡಿಕೆದಾರ' if lang == 'kn' else 'The investor' }}

Follows the log. Surprises that show up early are cheap; surprises that show up at harvest are not.

{{ 'ಸೈಟ್' if lang == 'kn' else 'The site' }}

Keeps the log in one place, next to the plan it belongs to.

5

{{ 'ಕೊಯ್ಲು ಮಾರಾಟವಾಗುತ್ತದೆ' if lang == 'kn' else 'The harvest sells' }}

{{ 'ಬೆಳೆಗಾರ' if lang == 'kn' else 'The grower' }}

Sells at the mandi or on contract and shares the receipts.

{{ 'ಸೈಟ್' if lang == 'kn' else 'The site' }}

Records the sale in the log. The money does not pass through the site.

{{ 'ಕಾಗದದಲ್ಲಿ' if lang == 'kn' else 'On paper' }}

Receipts, as they would be on any farm.

6

{{ 'ಲಾಭ ಹಂಚಿಕೆಯಾಗುತ್ತದೆ' if lang == 'kn' else 'Proceeds are split' }}

{{ 'ಹೂಡಿಕೆದಾರ' if lang == 'kn' else 'The investor' }}

Gets the listed costs back first, then the agreed percentage of what is left.

{{ 'ಬೆಳೆಗಾರ' if lang == 'kn' else 'The grower' }}

Takes the rest of the surplus. If the sale did not cover the costs, the share is zero.

{{ 'ಕಾಗದದಲ್ಲಿ' if lang == 'kn' else 'On paper' }}

Settlement as signed. See the arithmetic →

{{ 'ಉಳಿದ ದಾರಿಗಳು' if lang == 'kn' else 'The other ways' }}

{{ 'ಅದೇ ಆಕಾರ, ಬೇರೆ ಗಡಿಯಾರ.' if lang == 'kn' else 'Same shape, different clock.' }}

A crop season is one of five. The others follow the same steps with a different cycle and a different thing being funded.

{{ t('kind.livestock') }}

The cycle is months, not one harvest: nine for a lamb crop, eighteen for a dairy unit to reach a full lactation. Losses are part of the plan, not a footnote.

{{ t('kind.space') }}

A shed or a 30 by 40 site, funded in batches that take weeks. The budget separates the one-time setup from each batch.

{{ t('kind.shares') }}

Five acres or more in equal shares. A share is a share of one cycle’s work, never of the land, and the number of people per parcel is capped.

{{ t('kind.lease') }}

List, agree terms, sign a fixed-term licence drafted for Karnataka, then renew or move on. The term ends on its date.
{{ 'ಸೈಟ್ ಏನು ಮಾಡುತ್ತದೆ' if lang == 'kn' else 'The site’s job' }}

{{ 'ಏನು ಮಾಡುತ್ತದೆ, ಏನು ಮಾಡುವುದಿಲ್ಲ.' if lang == 'kn' else 'What it does, and what it does not.' }}

{{ 'ಮಾಡುತ್ತದೆ' if lang == 'kn' else 'It does' }}
  • Puts the parcel or the plan in front of people.
  • Passes on your phone number when someone writes to you.
  • Keeps the plan, the photographs, the budget and the log in one place.
  • Shows the money arithmetic, including the failed-season case.
{{ 'ಮಾಡುವುದಿಲ್ಲ' if lang == 'kn' else 'It does not' }}
  • Hold deposits, collect rent, or move money.
  • Execute any agreement. You sign on paper, with your own witnesses.
  • Verify title. Ask for the RTC (pahani) and read it, the way you would anyway.
  • Guarantee any return, or promise a yield.

{{ 'ಇದರ ಬೆಲೆ ಎಷ್ಟು?' if lang == 'kn' else 'What it costs' }}

Nothing, during the pilot. We are not charging investors, growers, owners or farmers while we are still proving this on our own 15 acres. When there is a fee it will be stated on this page before it applies to anyone.
